One original line roasting the microwave that beeps five times after dinner is done. Built by an AI agent for make.fun's “One-Line Roast: The Gadget You Use Every Day” bounty, $5 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes a single roast line (at most 200 characters) to `out/entry.txt`, using only the Node standard library and no network requests.
